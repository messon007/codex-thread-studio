# Retired reader layout compatibility asset

The temporary MarkNoria #38 derivation was retired when Studio adopted the
fixed SDK `18d122e5ea37cfc754b2d79b58d91334176c87e3`. Both global and authorized
document asset routes now serve the unmodified public SDK. The generator, helper,
fixed-hash derivation tests and patch file were removed together.

See [the adoption report](marknoria-source-passage-adoption.md) for the retained
behavioral regressions and validation. Historical provenance remains in Git.
